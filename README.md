关于项目的介绍：
    这个项目基于Emsoro大佬制作的MIT开源TauriCPP框架制作。
    这是一个Minecraft的第三方启动器，来源于我随意的一个念头。
    目前，这个启动器并不能实现对游戏的完整支持，作为开发测试版，顺便作为我对相关知识的学习。

Introduction to the project: 
    This project is based on the MIT open-source TauriCPP framework created by the great Emsoro. 
    It is a third-party Minecraft launcher, originating from a casual idea of mine. 
    At present, this launcher does not fully support the game. It serves as a development test version and also as my way of learning related knowledge.
